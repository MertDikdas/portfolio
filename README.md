# Mert Portfolio — Empty but Live

Minimal React + Vite portfolio starter for the "Empty but Live" milestone.

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Deploy to Vercel

1. Push this folder to a GitHub repository.
2. Import the repository into Vercel.
3. Framework preset: Vite
4. Build command: `npm run build`
5. Output directory: `dist`
6. Deploy.
7. Open the live URL on your phone and take a screenshot.
